You are analyzing pages from the Bellicorum Instrumentorum Liber
by Giovanni Fontana (Munich, BSB Cod. icon. 242), a manuscript
from the 1420s–1430s, northern Italy (Padua/Venice region).

This manuscript contains:
  (a) Sections of plain Latin or Italian text
  (b) Sections of text written in a substitution cipher
  (c) Fantastical technical illustrations

The cipher is the primary target. The cipher uses geometric
symbols constructed from a small set of base forms modified by
the addition or placement of strokes — creating a family of
related signs that encode different letters by systematic
variation of one feature.

DO NOT attempt to decode the cipher or map signs to letters
unless Fontana provides an explicit key on the page. Describe
only what you observe visually. The construction logic —
how signs relate to each other — is what matters, not the
individual letter values.

WHAT TO SKIP — output nothing for any of the following:
─────────────────────────────────────────────────────────────
- The illustrations themselves — for each illustration,
  record only a one-sentence visual description in the
  page_illustration_description field; do not describe

- Latin/Italian prose text sections that discuss the
  illustrations or engineering topics — transcribe only

- Blank or decorative pages
- Ownership stamps, library seals, later annotations by

OUTPUT FORMAT — three parallel arrays per page:
─────────────────────────────────────────────────────────────

For each page provide a single JSON object with these keys:

1. folio
   The folio number as written on the page (e.g. "f. 12r",
   "f. 12v"). If not visible, write null.

2. page_type
   Classify the page content:
   "cipher_text"    — page contains cipher writing
   "plain_text"     — page contains Latin/Italian prose only
   "cipher_key"     — page shows a cipher alphabet or key table
   "illustration"   — page is primarily an illustration
   "mixed"          — combination of the above

3. page_illustration_description
   If an illustration is present, one sentence describing
   what it depicts visually. Null if no illustration.

4. plain_text_transcription
   If plain Latin or Italian text is present, transcribe it
   exactly. Null if no plain text.

5. cipher_signs
   Array of sign objects for each distinct cipher symbol
   visible on this page. If a symbol repeats, record it
   once in the catalog (first occurrence only) unless it
   appears in a cipher key alongside a letter value.

   For each distinct cipher sign:

   a. sign_id
      Your assigned identifier for this sign across the
      full manuscript: "F01", "F02", etc. Use the SAME
      identifier each time this sign recurs.

   b. base_form
      The primary geometric shape:
      "circle", "oval", "vertical_stroke",
      "horizontal_stroke", "diagonal_left", "diagonal_right",
      "open_curve_left", "open_curve_right", "closed_loop",
      "hook", "angle"

   c. added_feature
      The feature added to or modifying the base form.
      Describe using these terms:
      "tick_up", "tick_down", "tick_left", "tick_right",
      "tick_northeast", "tick_northwest", "tick_southeast",
      "tick_southwest", "tick_internal", "tick_external",
      "crossbar", "dot_inside", "dot_outside", "loop_added",
      "stroke_through", "mirrored", "rotated_90",
      "no_addition" (if the base form alone)

   d. letter_value
      If Fontana provides a letter value on THIS PAGE
      (in a key or annotation), transcribe it exactly.
      Null if no value given on this page — do not infer.

   e. family_relationship
      If this sign is clearly related to another sign by
      sharing its base_form but differing in added_feature,
      list the sign_ids of the related signs. [] if none
      identified yet.

   f. first_occurrence_folio
      The folio where you first catalogued this sign.

   g. confidence
      "high" / "medium" / "low"

6. cipher_key_entries
   If this page shows a cipher alphabet table or key:
   array of {symbol_description, letter_value, confidence}.
   [] if no key present.
