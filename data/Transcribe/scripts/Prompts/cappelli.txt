You are extracting dictionary entries from Cappelli's Lexicon Abbreviaturarum
(1928 German edition). This is a printed reference dictionary of medieval Latin
and Italian manuscript abbreviations used in documents from roughly the 6th
through 16th centuries.

─────────────────────────────────────────────────────────────
WHAT TO SKIP — output nothing for any of the following:
─────────────────────────────────────────────────────────────
- Title page, copyright page, publisher information
- Preface, Vorwort, introduction, or any block of prose text
- Bibliography or Literaturverzeichnis sections
- Instructions for use
- Running page headers (e.g. "A" or "Ab — Ac" at top of page)
- Single large capital letters that mark the start of a new
  alphabetical section (the big "A", "B", "C" dividers)
- Entries that consist ONLY of a cross-reference such as
  "v. [word]" or "siehe [word]" with no expansion given —
  skip these entirely
- Any footnote that is an editorial comment rather than
  part of an entry
- Any appendix or supplementary table at the end of the book

─────────────────────────────────────────────────────────────
WHAT TO EXTRACT — one JSON object per dictionary entry:
─────────────────────────────────────────────────────────────
A dictionary entry is a line (or short group of lines) that
contains an abbreviated form followed by its full expansion.
The entry format is typically:

  [abbreviated form]  [expansion]

Sometimes separated by a period, equals sign, or space.

For each entry extract:

1. abbreviated_form
   Transcribe the abbreviated form EXACTLY as printed.
   Preserve all visible marks. For special symbols that are
   not standard A-Z letters, do NOT substitute Unicode.
   Instead, transcribe the letters you can read and add
   a bracketed visual description for any non-letter mark.
   Use these description terms for common Cappelli symbols:

     [macron]          — horizontal bar over a letter
     [tilde]           — wavy curl over a letter
     [sup:X]           — superscript letter X
     [9-sign]          — the number-9-like symbol (= con/cum/que)
     [p-stroke]        — p with a horizontal stroke through
                         the descender (= per/pre/pro)
     [tironian-et]     — the 7-like symbol for "et"
     [semicolon-mark]  — semicolon used as abbreviation mark
     [dot-above]       — raised dot above a letter
     [stroke-through]  — a stroke through the body of a letter
     [loop-on]         — a small loop attached to a letter
     [overline]        — bar over multiple letters as a group

   Example: a "q" with a superscript "a" should be written:
     q[sup:a]
   A "p" with a stroke through the descender:
     p[p-stroke]
   An "m" with a wavy curl above it:
     m[tilde]

2. visual_description
   ONLY populate this field if the abbreviated form includes
   a drawn symbol or non-standard glyph — meaning a mark that
   is NOT simply a letter with a superscript, macron, or tilde.
   
   Examples that DO need visual_description:
   - A gallows-like form (tall vertical with an arch or loop at top)
   - A symbol that resembles a number or figure rather than a letter
   - The 9-sign, Tironian et, or p-stroke described as standalone signs
   - Any symbol that could plausibly be compared to a Voynich glyph
   
   Examples that do NOT need visual_description (write null):
   - Standard letters with macrons: a[macron], m[tilde]
   - Standard superscripts: q[sup:a], p[sup:r]
   - Plain letter abbreviations: a.C., A.D.
   
   When visual_description IS needed, describe the drawn form
   using ONLY these stroke terms:
   vertical_stroke, horizontal_stroke, diagonal_left, diagonal_right,
   open_curve_left, open_curve_right, closed_loop, hook_up, hook_down,
   ascender, descender, crossbar, sigmoid, connector, serif_present
   
   Format: describe the strokes in order of drawing, e.g.:
   "ascender with closed_loop at top, descender curving right"

3. latin_expansion
   The full word or phrase that the abbreviation stands for.
   Transcribe exactly as printed. If the expansion contains
   a language indicator such as (L.) for Latin or (I.) for
   Italian, include it verbatim.

4. language
   "latin"   — if the expansion is Latin or labelled (L.)
   "italian" — if the expansion is Italian or labelled (I.)
   "unclear" — if you cannot determine

5. century_ref
   If a century or date is given (e.g. "XII.", "XIV.", "s.XV"),
   transcribe it exactly as printed. Otherwise null.

6. provenance
   If the entry carries a regional or document-type label,
   transcribe it exactly. Examples to watch for:
     "lomb."       — Lombard documents
     "lomb. Urk."  — Lombard charters/deeds
     "ital."       — Italian (general)
     "not."        — notarial documents
     "it. Urk."    — Italian charters
     "venez."      — Venetian
     "gen."        — Genoese
     "mil."        — Milanese
   Transcribe whatever label Cappelli prints, exactly.
   Null if no regional or document-type label is given.

7. semantic_domain
   Classify the Latin expansion into one of these domains.
   This is the ONE field where you apply judgment — infer
   from the Latin expansion what subject area it belongs to:
     "pharmaceutical"  — medicines, preparations, remedies
     "botanical"       — plants, herbs, plant parts
     "medical"         — anatomy, conditions, procedures
     "legal"           — legal terms, charters, documents
     "liturgical"      — church, religious, liturgy
     "administrative"  — governance, titles, offices
     "temporal"        — dates, times, calendrical
     "general"         — common Latin words not in above
     "unclear"         — cannot determine from expansion alone
   Use "unclear" if the expansion is too abbreviated to classify.

8. page
   The page number as printed at the bottom or top of the page.
   If not visible, write null.

9. has_special_symbols
   true if the abbreviated_form contains any non-letter mark;
   false if it contains only standard A-Z letters and punctuation.

10. priority
    Assign a priority level for the analytical pipeline.
    Set to "high" if ANY of the following are true:
    - century_ref falls in XIII, XIV, or XV (the Voynich period)
    - provenance is Lombard, northern Italian, or notarial
    - has_special_symbols is true AND visual_description is not null
      (i.e. it has an actual drawn symbol, not just a macron)
    - semantic_domain is "pharmaceutical", "botanical", or "medical"
    Set to "normal" otherwise.

11. confidence
    "high"   — you can read both fields clearly
    "medium" — one field has minor uncertainty
    "low"    — significant uncertainty in either field

─────────────────────────────────────────────────────────────
RULES:
─────────────────────────────────────────────────────────────
- If you cannot read a field confidently, write null — never guess
- Do not translate, interpret, or expand abbreviations yourself
- Do not add explanatory text outside the JSON
- If a single abbreviated form has multiple expansions listed
  on the same line, create one JSON object per expansion
- visual_description is null for the vast majority of entries —
  only populate it for genuinely drawn/glyph-like symbols

Output ONLY a JSON array. No explanation, no preamble,
no markdown fences, no trailing commentary.

  "page": <integer or null>,
  "abbreviated_form": <string or null>,
